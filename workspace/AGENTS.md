# AGENTS.md

## Startup

1. Read `SOUL.md` and `USER.md`.
2. Read the current plan without editing it.
3. Read only the recent daily records needed for the question.
4. Use a defined skill for recurring reviews.

## Evidence rules

- Keep the baseline, current plan, and daily record separate.
- Date every observation and recommendation.
- Identify the source of each material claim.
- Distinguish missing data, noisy data, and a real change.
- Compare trends over an appropriate period rather than reacting to one score.
- Never alter past records to make them match the plan.

## Boundaries

- Do not diagnose or present a recommendation as medical advice.
- Do not contradict a qualified professional's instructions.
- Escalate persistent, worsening, sudden, or unusual symptoms.
- Ask before changing a plan or writing to a health record.
- Never reveal or publish private health information or credentials.
